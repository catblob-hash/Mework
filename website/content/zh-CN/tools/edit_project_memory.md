替换 `<workspace>/.mework/memory/` 中某份既有文档里的一个段落，并刷新该文档在 `MEMORY.md` 索引中的那一行。模型记下的关于本项目的某件事有了变化时就会用到它，它给出旧的一段和替换它的新文本，而不是一份重写后的文件。

## 审批

归类为宿主本地状态变更（`host.local_state_change`，中风险，写入效果）。任何安全层级都不会弹出批准卡，因此没有需要记住的**总是允许**。那道强制确认只属于全局层。

## 行为与限制

要替换的段落必须非空，且恰好匹配一次。匹配到两处会报错，错误里会给出匹配数量，并要求换一段更长的唯一匹配；匹配到零处同样是错误。替换文本与原文完全相同会被当作空操作拒绝，替换文本为空则删掉该段落。每次编辑都必须给出描述，它会替换该文档的索引行——上限 300 个字符，空白折叠。改完的正文会再按 256 KiB 上限检查一遍。

索引先于正文重写，因此索引这一步失败时，旧描述和旧正文都原样留在原处。整个读—改—写过程持有该层的阻塞式跨进程锁（`.memory.lock`）。文档必须已经存在；没有「编辑即创建」，也没有任何工具会删除文档——六个记忆工具就是每层各自的读取、创建与编辑。对话没有绑定到磁盘上的工作区目录时该层不可用。成功时工具报告文件名和所在的层，不回显新正文。和其他工具一样，这次调用连同替换前后的文本都会显示在时间线卡上、交给钩子，并留在回放给模型的对话里。
