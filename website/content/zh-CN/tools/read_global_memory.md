返回全局记忆目录 `~/.mework/memory/` 中某一份文档的完整正文。全局记忆开关开启时，该层的 `MEWORK.md` 及其 `MEMORY.md` 索引会随请求一同送出；索引只列出文档名和各自的一行描述，从不包含正文。模型会在某条索引行看起来相关时调用它。

## 审批

归类为对宿主状态的读取（`host.read_or_coordinate`，低风险，读取效果）。任何安全层级都不会弹出批准卡，计划模式也不例外，因此没有需要记住的**总是允许**。

## 行为与限制

`name` 是记忆目录内的单个叶子名称，绝不是路径。`.md` 后缀可省略，匹配时不区分大小写；连同后缀在内的整个名称上限 120 个字符。路径分隔符、`..`、冒号、前导点、控制字符、结尾的点或空格、`< > " | ? *` 以及 Windows 设备名（`CON`、`NUL`、`COM1`）一律直接拒绝，而不是做清洗处理，因此被拒的名称绝不会解析到另一份文档上。

`MEMORY.md` 无论怎么拼写都无法寻址：索引归宿主所有，由它依据 create 与 edit 工具携带的描述重写。

文件通过不跟随链接的句柄打开——路径上的符号链接或重分析点（reparse point）会直接失败，而不会被跟随——并且必须是有效的 UTF-8，且不超过 256 KiB；超限的文档会被拒绝，而不是截断。模型拿到的正文一字不差；时间线卡、钩子载荷与回执只保留操作、层、名称和一个字节数。文档不存在时只报告查过哪一层，不透露任何路径。平台报告没有主目录时该层不可用；全局记忆开关关闭时调用被直接拒绝。
