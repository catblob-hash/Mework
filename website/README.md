# Documentation site

The public documentation at <https://catblob-hash.github.io/Mework/> is built from this directory.

```text
website/
  content/en/*.md        English pages (authoritative; written by hand)
  content/zh-CN/*.md     Chinese pages (translated from the English pages)
  assets/style.css       the one stylesheet
```

`scripts/build-site.mjs` turns every page into static HTML under `website/dist` (ignored by git). It has one dependency, `marked`, which `npm install` at the repository root provides; the GitHub Actions workflow in `.github/workflows/pages.yml` runs `npm ci --ignore-scripts` at the repository root before building.

```bash
npm run site:build       # build into website/dist
npm run site:preview     # build, then serve on http://127.0.0.1:4173/
```

Two placeholders are expanded at build time from the generated design baselines in `docs/context-injections/` (regenerated by `cargo test --lib -- prompt_profile::tests::regenerate_prompt_profile_baselines --ignored`):

- `{{PROMPT_KEYS_TABLE}}` — the complete injection-point reference with the English and Chinese built-in texts.
- `{{PROFILE_FILE_LINKS}}` — download links for the two built-in profile files and the key manifest, which the build copies into `website/dist/files/`.

Pages are listed in `PAGES` inside the build script; a page must exist in both languages. The first `# ` heading of a page is its title; the short navigation labels come from `NAV_LABELS` in the build script.

## Publishing

The workflow runs on every push to `main` that touches the site sources and deploys with `actions/deploy-pages`. In the repository settings, Pages must use **Source: GitHub Actions** (the workflow also asks GitHub to enable it on first run). The site is served under `/Mework/`, and every link in the generated pages is relative, so it also works from any other base path or from a local file server.
